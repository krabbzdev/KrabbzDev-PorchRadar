# Security

If you find a security problem in Porch Radar, please report it privately so it can be fixed before it is public:

**[Report a vulnerability](https://github.com/krabbzdev/KrabbzDev-PorchRadar/security/advisories/new)** (GitHub's private form: only the maintainer can see it).

Please don't post the details in a public issue. You can also open the app's floating **Feedback** button, say it is a security problem in the title and leave the details out, and I'll get in touch.

Porch Radar runs on your own PC, sends nothing to its author and keeps your settings in `settings.json` next to the program. See [PRIVACY.md](PRIVACY.md) for what it contacts.
